# DESCRIÇÃO DO MODELO RELACIONAL

A Descrição do Modelo Relacional é um modelo lógico de uma base dados, feita a partir de um
Diagrama-Entidade-Relacionamento, aproximando os dados à forma que eles são representados e armazenados
nos bancos. Introduzindo o conceito de tipos aos atributos, e já definindo como mais exatidão as
tabelas do programa, eliminando relacionamentos N:N, especializações, relacionamentos com atributos, entre outros,
por meio de regras de conversão, as quais estão aquém do escopo dessa documentação, mas podem ser encontradas no
material utilizado para escrevê-la.

O programa apresenta aos usuários de um _Rich Text Editor_(editor de texto rico em tradução literal) com as opções de
formatação mais utilizadas para a construção de descrições, como negrito, itálico e sublinhado. Além de cores, a fim de
facilitar a organização pessoal do usuário.
